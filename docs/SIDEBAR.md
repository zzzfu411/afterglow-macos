# Moro 0.7.0 使用方式

左侧负责导航，右侧展示事项。计时收在底栏，需要时才打开专注视图。

## 窗口与清单

| 区域 | 内容 |
| --- | --- |
| 导航侧栏 | 收件箱、今天、接下来、全部、自定义清单、已完成、最近删除 |
| 主列表 | 标题快速录入、事项、按需展开的详情、批量操作 |
| 标题栏 | 侧栏开关、搜索、自由专注、记录、设置 |
| 底部控制栏 | 当前事项、剩余时间、暂停 / 继续、结束及队列下一项 |

默认窗口为 760 × 540 pt，最小 360 × 400 pt。侧栏默认约 196 pt，可在 160–260 pt 内调整；窗口窄于 560 pt 时自动收起。`⌘ B` 或标题栏按钮控制显示，偏好会保留。

主列表使用系统实色阅读面；侧栏使用随窗口激活状态变化的原生材质，尊重“减少透明度”。系统字体、语义颜色与浅深色外观共同保证可读性。大窗口增加清单空间，不把时钟无限放大。

## 录入、编辑与恢复

| 操作 | 结果 |
| --- | --- |
| `⌘ N`，输入标题，Return | 保存新事项；其他信息都可留空 |
| 点完成框 | 完成或恢复该事项 |
| 点标题 | 选择并展开详情，不启动计时 |
| 点 ▶ | 为这一项开始专注 |
| 点 `···` 或右键 | 安排日期、选择专注时长、移动或删除 |
| `⌘ Z` / `⇧⌘ Z` | 撤销 / 重做任务操作；输入框内优先处理文字 |

在“今天”新增会安排到今天；在自定义清单新增会归入该清单。在“接下来”录入没有日期的新事项后，会进入收件箱。独立快速录入始终保存到收件箱。

详情支持备注、预计时长、计划日期、截止日期、提醒、步骤和重复规则，保存后生效。预计时间可留空，也可超过三小时；本轮专注时间独立设置。未保存草稿不会因隐藏侧栏、搜索或计时而被覆盖；切换编辑对象前会要求保存或取消，放弃修改有确认。

删除先进入“最近删除”，可以恢复。永久删除需再次确认。删除自定义清单会把其中的事项移回收件箱。完成、恢复、编辑、移动、删除和导入支持有界的会话内撤销；退出后不保留撤销栈。撤销完成不会回滚或重启已经结算的计时。

支持 `⌘` 多选与 `⇧` 范围选择，再批量完成、恢复、安排、移动或删除。列表按 100 项分批显示，“显示更多”继续展开；从当前专注或通知定位任务时，会展开到该任务所在分页。

## 计划、截止与提醒

| 字段 | 规则 |
| --- | --- |
| 计划日期 | “打算哪天做”；改期不会推迟 deadline |
| 截止日期 | “最迟何时完成”；可仅设日期，也可添加时间 |
| 提醒时间 | 单独选择日期与时间；只设 deadline 不发送通知 |

“收件箱”包含没有所属自定义清单的未完成事项。“今天”包含安排到今天及以前的未完成事项，以及今天到期或逾期事项。“接下来”展示有未来计划或截止日期的事项，按最近的未来日期排序；同一事项只出现一次。

普通清单默认按截止日期排序，无日期事项在后；截止值相同时保留手动顺序，再按原有顺序排列。手动排序可拖动调整；搜索和编辑期间不拖排。日期型截止到次日才算逾期，带时间的截止按具体时刻判断。

提醒只针对未完成且未删除的事项。设置提醒或手动启用时请求通知权限，后台刷新不弹出授权请求；拒绝权限不影响保存事项。修改、完成和删除会重新协调通知。优先排入最近 48 项，其余数量与失败信息在设置中显示；激活应用、唤醒或事项变更时补排，没有后台轮询。未排入的提醒不会在退出应用后自动补排。

## 搜索、步骤与重复

`⌘ F` 搜索标题和备注，普通视图跨清单搜索所有未删除事项，包含已完成事项；最近删除中的搜索只查已删除项。搜索只筛选展示，不更改正在进行的专注。

步骤是一级清单，勾选步骤不等于完成父事项。重复规则可选每天、每周、每月，按设置时的时区与起始日期计算；完成后只生成一个未来事项，不补出一串过期事项。月末按当月最后有效日期处理，再回到原定日期。重新打开并完成同一次事项不会重复生成下一次。

## 专注与队列

▶ 直接使用记住的默认时长。旁边时长菜单提供 15 / 25 / 45 分钟和自定义 1–180 分钟；成功确认后记住选择，不修改预计时长。在已有专注时切换事项或重新指定时长，需要确认结束当前一轮。

清单菜单可“依次专注当前清单”；列表尚有未加载分页时，菜单明确为“依次专注已显示事项”。多选菜单也可为选中事项建队列，按列表显示顺序推进。每轮只关联一个事项；到点、跳过不会自动完成，下一项仍需点击。已完成或已删除的后续事项会跳过。

计时期间可以新增、搜索和编辑其他事项。点底栏的事项名称可回到它的详情；有未保存的其他草稿时先处理草稿。计时按保存的截止时间恢复，暂停时不累计投入；完成正在专注的事项会结算当前一轮。

单项统计只汇总保留日志中明确关联该 ID 的记录。系统最多保留最近 1,000 条专注日志；旧的整单记录或无 ID 记录不分摊给单项，也不按标题猜测，因此统计不代表终身累计。

## 快捷键与独立录入

| 快捷键 | 操作 |
| --- | --- |
| `⌘ N` → Return | 连续添加事项 |
| `⌘ B` | 开关导航侧栏 |
| `⌘ F` | 搜索 |
| `⌘ Z` / `⇧⌘ Z` | 撤销 / 重做 |
| `⌘ Return` | 开始 / 暂停 / 继续专注 |
| `Space` | 仅在专注视图控制计时 |
| `⌘ .` | 结束本轮 |
| `⌘ ,` | 设置 |

文字输入期间优先处理编辑操作，Space 不控制清单视图的计时。中文输入法确认候选词不会提交事项。

从菜单栏或“文件 → 快速录入…”打开独立输入框。全局快捷键默认关闭，设置中可选 `⌃⌥ Space`、`⌃⌥ N`、`⌃⇧ N`；启用失败保留原绑定并显示原因。VoiceOver 使用 `⌃⌥` 时可改用 `⌃⇧ N`。

独立录入只向收件箱保存事项，不切换主窗口清单或替换编辑草稿。Return 保存成功才清空、收起；失败保留输入，Esc 或失焦收起时保留草稿。应用退出后不保存未提交的快速录入草稿。

数据上限、归档与升级备份见 [构建与安装](BUILDING.md#数据备份与升级)，实际资源测量见 [PERFORMANCE.md](PERFORMANCE.md)。
