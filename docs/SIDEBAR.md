# 待办边栏

Moro 采用左右两栏：左侧选择和整理事项，右侧进行这一轮专注。清单保持可见，切换事项时不需要反复打开弹层。

## 布局

| 区域 | 内容与操作 |
| --- | --- |
| 系统标题栏 | 原生窗口按钮、边栏开关、记录、设置；空白位置可拖动窗口 |
| 左侧顶部 | “待办”和新增按钮；自由专注、整张清单两个入口 |
| 左侧清单 | 事项名称、预计分钟数、可选截止时间、明确的选择状态；独立滚动 |
| 左侧完成区 | 默认折叠，展开后每项可直接恢复待办 |
| 左侧底部 | 最近一次完成操作的撤销入口 |
| 右侧 | 专注／休息、当前事项、大号时间、时长选择与计时按钮 |

初始窗口 620 × 480 pt。边栏默认 210 pt，可在 160–340 pt 间调宽；上限随窗口宽度收缩，为右侧计时内容保留至少 320 × 400 pt 的空间。边栏展开时，窗口总宽下限为 481 pt，不再按默认栏宽锁住窗口。窄栏省去重复的“专注”文字，恢复待办改用带提示的回转箭头；日期和时间可换行，编辑表单独立滚动。收起边栏后可恢复 320 pt 的最小宽度；大窗口下限制计时内容宽度，避免数字无限放大。

沿用系统字体、SF Symbols、原生材质和语义文字颜色。使用轻量选中底色，不给每个事项添加卡片边框。主界面不放使用说明。

## 操作约定

- 点事项的圆点、名称或“专注”只选择事项并带入时间，保持边栏展开；仍由右侧开始按钮启动。
- 完成、编辑与删除放在事项的 `···` 菜单，也支持右键。完成与选择不会共用一个点击操作。
- 误标可撤销，已完成项可恢复。编辑清单不改变正在运行的截止时间或专注记录。
- 新增和编辑在左栏内进行；`⌘ N` 打开新增或未完成的草稿。收起边栏保留草稿，取消才丢弃。
- 标题栏边栏按钮或 `⌘ B` 控制显示，并记住偏好。点击右侧事项名称或菜单栏的事项入口会展开边栏。
- 浏览清单时空格可以控制计时；编辑待办、编辑时长、查看记录及确认删除时不触发计时快捷键。

## 截止时间

- 新建或编辑时可勾选“截止时间”，分别设置日期和时分；取消勾选后保存即可清除。默认不设日期，允许录入过去的日期。
- 未完成事项按截止时间升序排列，包括已过期日期；相同日期和无日期事项保持添加顺序，无日期事项统一置后。已完成事项仍在折叠区。
- 截止时间是事项的计划信息，不是专注计时器的结束时间，不单独发送通知。修改日期只重排清单，保留本轮截止时间、历史名称及用户调整的计时时长。
- 日期按本机时区编辑和显示，以绝对时间持久化。列表标明年月日和时间，完整日期也可通过悬停或无障碍标签读取。

## 资源与数据

采用 SwiftUI `NavigationSplitView`，由系统处理列宽和窗口分隔。事项区域沿用 `LazyVStack`，计时仍使用系统时间文本和单次截止时间唤醒。没有新增依赖、轮询或后台服务。

边栏偏好单独存于应用偏好设置。旧待办缺少截止时间字段时按无日期读取；仅保存首个截止时间时升级到第 3 版数据格式，并保持该版本以阻止旧应用覆盖新字段。只读展示和排序不会重写清单。日期编辑不创建额外计时器或轮询。
